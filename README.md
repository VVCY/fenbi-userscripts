# 粉笔网页版油猴脚本合集 粉笔脚本君出品
小红书：粉笔脚本君
作者：vvcy（[ScriptCat 主页](https://scriptcat.org/zh-CN/users/215061)）

适配粉笔网页版题库 / 在线试卷，配合 [ScriptCat](https://scriptcat.org/) 或 Tampermonkey 使用。

## 脚本列表

| 脚本 | 说明 |
|---|---|
| 粉笔试卷排版打印 魔改火焰百合|( 在排版打印基础上，支持勾选 / 自选题目后导出)把粉笔在线试卷（行测/申论）一键排版成 A4 真卷：题号悬挂缩进、屏幕直接显示 A4 分页、题目可跨页，支持直接打印或导出 PDF |
| 粉笔题库一键排版打印 魔改行测小助理 | 在排版打印基础上，支持勾选 / 自选题目后导出 |
| 粉笔一页成卷 | 粉笔网页版题目页就地套用《粉笔试卷排版打印》版式（宋体、默认字号 24px / 行高 1.6），`-`/`+` 加减调整 |
| 粉笔自由折叠 | 右上角常驻「显示设置」面板：一键开合所有题干/选项、答案显隐 |
| 粉笔自动全开草稿 | 页面加载后自动打开全部题的草稿，每题注入 ABCD 字母选择盒，草稿画布锁定为题干预览高度 |
| 粉笔题库 - 试卷跳转面板 | 右上角悬浮展开年/季/类别面板，季选项标注当前类别完成情况，直接跳转对应试卷 |
| 粉笔评论查看器 | 查看/收藏粉笔题库优质评论 |
| 粉笔题库 · 悬浮查词 | 在粉笔题库页面悬浮查成语/词语释义 |

## 安装

1. 安装 [ScriptCat](https://scriptcat.org/)（或 Tampermonkey）浏览器扩展
2. 打开对应 `.user.js` 文件，点「Raw」或直接拖拽进浏览器即可安装

## 说明

- 脚本均为本地运行，不上传任何做题数据
- 仅适配粉笔网页版（`spa.fenbi.com` / `www.fenbi.com`）
